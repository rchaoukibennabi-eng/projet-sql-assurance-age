# Mini-Projet SQL – Assurance & Calcul de l'âge

## 📌 Description
Ce projet SQL a pour objectif de gérer des clients d'assurance et de calculer leur âge à partir de leur date de naissance.
Il permet de réaliser des analyses simples utilisées dans le domaine de l'assurance.

## 🛠️ Technologies
- SQL Server
- SQL Server Management Studio (SSMS)

## 📊 Fonctionnalités
- Création d'une base de données assurance
- Gestion des clients
- Calcul précis de l'âge
- Analyse par tranche d'âge
- Analyse par type de contrat

## ▶️ Utilisation
Exécuter les scripts SQL dans l'ordre indiqué dans le dossier `sql/`.
