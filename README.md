# Mini-projet SQL – Assurance et calcul de l’âge

## Présentation

Ce mini-projet a pour but de manipuler le langage SQL à travers un exemple lié au domaine de l’assurance.
Il consiste à gérer des informations sur des clients et à calculer leur âge à partir de leur date de naissance. Ce type de calcul est couramment utilisé en assurance, notamment pour la tarification ou l’analyse de portefeuilles clients.

Le projet reste volontairement simple afin de se concentrer sur la logique SQL et la manipulation des données.

---

## Technologies utilisées

Le projet a été réalisé avec :
- SQL Server
- SQL Server Management Studio (SSMS)

---

## Contenu et fonctionnalités

Le projet permet notamment de :
- créer une base de données dédiée à l’assurance ;
- stocker les informations des clients ;
- calculer l’âge des clients de manière précise à partir de leur date de naissance ;
- regrouper les clients par tranche d’âge ;
- effectuer des analyses simples selon le type de contrat.

Ces fonctionnalités permettent de simuler des analyses basiques que l’on peut retrouver dans un contexte réel d’assurance.

---

## Utilisation

Pour utiliser ce projet, il suffit d’exécuter les scripts SQL dans l’ordre indiqué dans le dossier `sql/`.
Chaque script correspond à une étape précise : création des tables, insertion des données et requêtes d’analyse.

---

## Remarques

Ce projet peut servir de base pour des analyses plus avancées ou être enrichi par la suite avec d’autres tables ou indicateurs.
