# Rapport – Mini-Projet SQL Assurance

## 1. Contexte
Ce projet vise à simuler la gestion des clients d'une compagnie d'assurance.

## 2. Objectifs
- Stocker les informations clients
- Calculer précisément l'âge
- Réaliser des analyses simples

## 3. Méthodologie
L'âge est calculé à partir de la date de naissance en utilisant les fonctions SQL
DATEDIFF et DATEADD afin d'obtenir un résultat exact.

## 4. Résultats
Les requêtes permettent d'identifier les clients assurables, d'analyser la répartition
par tranche d'âge et de calculer l'âge moyen par type de contrat.

## 5. Conclusion
Ce projet montre l'utilisation de SQL Server dans un contexte assurantiel et constitue
une base pour des analyses actuarielles plus avancées.
